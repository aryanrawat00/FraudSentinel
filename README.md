# FraudSentinel

A Secure AI-Powered Financial Fraud Detection
and Investigation Platform.

## Technology Stack
- React + TypeScript
- FastAPI
- PostgreSQL
- Scikit-learn
- Open Policy Agent (OPA)

## Core Features
- Fraud Detection
- Explainable AI Investigation
- AI Agent Security Firewall
- Evidence-Based Reports

## Development workflow

This repository is connected to
[aryanrawat00/FraudSentinel](https://github.com/aryanrawat00/FraudSentinel)
and currently uses `main`, tracking `origin/main`.

Follow [CONTRIBUTING.md](CONTRIBUTING.md) for local verification, meaningful
module commits, secret handling, and the required changed-file and commit
summary before each push. Environment files, credentials, local datasets,
database files, and generated artifacts are excluded by `.gitignore`.
